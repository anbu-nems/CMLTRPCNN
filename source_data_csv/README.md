# Source Data — per-panel CSVs (2026-05-26)

One CSV per figure panel, holding **exactly the values plotted** in that panel. Generated by
capturing every matplotlib draw call (`scripts/gen_source_data_csv.py`) while running the
unmodified figure scripts — so each file matches its figure by construction.

- Main figures use **manuscript numbering**: `Fig1*`, `Fig2*`, `Fig4*`, `Fig5*`, `Fig6*`.
  (Fig 3 = architecture schematic → no plotted data, no CSV.)
- Supplementary: `figS1*`…`figS23*` (figS20 = mechanism schematic → no CSV).
- Panel suffix = panel letter (e.g. `Fig6a.csv`, `figS9c.csv`); single-panel figures have no suffix.
- Columns: plotted x/y/height/values; `label` = category names (A-site, B-site, regime…) where
  applicable; multi-series panels use `<kind>N_` prefixes; heatmaps are long-format (row/col/value).
